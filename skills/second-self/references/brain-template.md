# Second brain template

Private file. Default path: `~/second-self/brain.md`. Newest entries at
the top of each section. Never delete an entry: mark it superseded and
link the newer one.

Entry types:

| Type | Use for | Required fields |
|------|---------|-----------------|
| Decision | A choice made | context, options considered, choice, rationale, confidence, review date |
| Idea | Something to explore | context, next step if any |
| Belief | A view held about work, people, learning | statement, evidence, what would change it, confidence |
| Lesson | Something learned from an outcome | what happened, what to repeat or avoid |
| Question | An open question worth returning to | why it matters |
| Commitment | An action promised to oneself | if-then plan, due date, status |
